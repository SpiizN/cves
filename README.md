# CVEs

CVEs I have found, with the proof-of-concept code that goes with them.

Each one lives in its own `CVE-YYYY-NNNNN/` directory: the advisory in `README.md`, the PoC in `poc/`. Copy [`_template/`](_template/) to start a new one.

The table is generated by [`.github/actions/update_cves.py`](.github/actions/update_cves.py) and kept in sync by CI: it reads the title and the `**Severity:**` line of each advisory, so edit those, not the table. A directory whose name starts with `_` is ignored, so rename one to `_CVE-...` to park a draft.

## Disclosure

Vendors are notified first. Nothing is published here before a fix is available or the disclosure deadline has passed.

## Using the PoCs

Published for educational purposes only, so defenders can check whether they are affected. Run them only against systems you own or are authorized to test.
